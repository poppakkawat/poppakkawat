# Pixel Trading Floor

Dashboard การเทรดสไตล์เกม pixel ที่มีตัวละคร 8 ตัวใน 3 แผนก ข้อมูลอัปเดตเองทุก 30 นาทีผ่าน GitHub Actions
ไม่ต้องกรอกอะไรเอง

| แผนก | ราคาจริงที่ดึงมา | พอร์ตทดลอง (paper) |
|---|---|---|
| Return on Cash | อัตรา T-Bill 13 สัปดาห์ (`^IRX`) | เงินสด $5,000 รับดอกเบี้ยตามอัตราจริง ทบทุกรอบ |
| Beta · Oil Grid | WTI (`CL=F`) แท่ง 5 นาที | Grid ซื้ออย่างเดียว ห่างชั้นละ $0.50, 25 ชั้น, 10 bbl/ชั้น (0.01 lot) |
| Alpha | หุ้น 12 ตัวใน watchlist + S&P 500 / SET50 | ทุกสัปดาห์ถือ 3 ตัวที่โมเมนตัม 20 วันแรงสุด แล้ววัดผลเทียบดัชนี |

ราคาทั้งหมดดึงจาก Yahoo Finance (ฟรี ไม่ต้องใช้ API key) ส่วนพอร์ตเป็นเงินทดลองทั้งหมด

## เปิดใช้ครั้งแรก (ทำครั้งเดียว)

1. ไปที่ **Settings → Pages → Build and deployment → Source** แล้วเลือก **GitHub Actions**
2. ไปที่ **Actions → Pixel Trading Floor → Run workflow** เพื่อรันรอบแรกทันที
3. เปิด https://poppakkawat.github.io/poppakkawat/ ซึ่งเป็น dashboard ที่จะอัปเดตเองทุก 30 นาที

หน้าเว็บนี้เป็นสาธารณะ ใครมีลิงก์ก็เปิดได้ ตอนนี้แสดงแค่เงินทดลอง เมื่อจะต่อบัญชีจริงค่อยพิจารณาเรื่องความเป็นส่วนตัวอีกครั้ง

## ปรับค่า

แก้ `floor/config.py` แล้ว commit โดยแก้ได้ทั้งทุนแต่ละแผนก กรอบ Grid ระยะชั้น ขนาดต่อชั้น รายชื่อหุ้น และเป้ารายเดือน

สถานะพอร์ตเก็บอยู่ใน branch `floor-data` (`state.json`) ถ้าอยากเริ่มพอร์ตทดลองใหม่ทั้งหมด ให้ลบ branch นี้ทิ้ง

## รันบนเครื่องตัวเอง

```bash
python3 -m floor --state out/state.json --out out/data.json
cp floor/site/index.html out/ && cd out && python3 -m http.server 8000
# เปิด http://localhost:8000
```

## ข้อจำกัดที่ควรรู้

- `CL=F` เป็นสัญญาล่วงหน้าที่เปลี่ยนรุ่นทุกเดือน ถ้าราคากระโดดเกิน $2 ระหว่างแท่ง ระบบจะถือว่าเป็นช่องว่างหรือการเปลี่ยนรุ่น และไม่จับคู่ชั้นในช่องนั้น
- Grid จำลองจากแท่ง 5 นาที (เปิด → ต่ำ/สูง → ปิด) จึงไม่ได้หักสเปรด ค่าคอม หรือ swap แบบ CFD จริง
- แผนก Alpha ทดสอบย้อนหลัง 90 วันตั้งแต่รอบแรก แล้วเดินต่อแบบ paper โดยวัดผลเป็น % ของแต่ละตลาด ยังไม่แปลงค่าเงิน

## ต่อ MT5 (ขั้นถัดไป)

เปิดบัญชี demo ใน MT5 แล้วให้ EA ส่งข้อมูลยอดเงิน ออเดอร์ และสถานะเข้าระบบนี้ เพื่อแทน Grid จำลอง
พอร์ต Beta ก็จะเป็นข้อมูลจากโบรกจริงโดยไม่ต้องกรอกเหมือนเดิม
