อ่านไฟล์นี้ก่อนทำงานต่อ เมื่อบทสนทนาเดิมหมด context

## วิธีทำงานที่ตกลงกับผู้ใช้

1. ผู้ใช้ส่งคำ/วลีเวียดนามมาทีละคำ → Claude ตัดสินเองว่าเป็นฮั่นเวียด (Sino-Vietnamese) หรือไม่
   - มีพยางค์ฮั่นเวียดอย่างน้อยหนึ่งพยางค์ (รวมคำลูกผสม) → ชุด **ฮั่นเวียด** (`deck` ไม่ต้องใส่)
   - ไม่มีเลย → ชุด **คำอื่น ๆ** (`deck: "other"`, ใส่ `origin`)
   - ที่มาไม่แน่ชัด → ไม่ใส่ `han` ให้พยางค์นั้น และเขียนในหมายเหตุว่าไม่แน่ชัด
2. **พิมพ์ผิดบ่อย** (วรรณยุกต์/ตัวอักษรเกิน) → เดาคำที่น่าจะใช่ ใส่บัตร แล้วบอกผู้ใช้ว่าตีความเป็นคำไหน ถ้ากำกวมจริง ๆ ให้ถามก่อน (เช่น Nhũng → ถามแล้วได้ Những)
3. **คำซ้ำ** → ไม่เพิ่มซ้ำ บอกว่ามีแล้ว แนะนำให้ใช้ช่องค้นหา
4. **ที่มา (`src`)**:
   - ช่วงแรกผู้ใช้บอกว่า "เจอจาก ROV (Liên Quân Mobile) หมด" → ใส่ `src: "ROV (Liên Quân Mobile)"`
   - ตั้งแต่ **Lực chiến** เป็นต้นมา ผู้ใช้บอก "เว้นที่มาไว้" → **ไม่ใส่ src** จนกว่าผู้ใช้จะบอกที่มาเอง
   - Nổi tiếng ผู้ใช้บอกว่าไม่ได้มาจาก ROV
5. ทุกครั้งที่เพิ่มบัตร: ตรวจ syntax ของ script (`node --check`) แล้ว publish ไปที่ URL เดิม จากนั้นตอบสั้น ๆ: ความหมาย, แยกพยางค์, คำที่ใช้ตัวอักษรเดียวกัน, ข้อควรระวัง, จำนวนบัตรในแต่ละชุด
6. ภาษาที่ใช้ตอบ: ไทย

## โครงสร้างข้อมูลบัตร (ใน `const WORDS = [...]`)

```js
{
  deck: "other",                 // ไม่ใส่ = ชุดฮั่นเวียด
  origin: "คำเวียดแท้ (thuần Việt)", // ใช้กับชุด other
  vi: "Khách sạn", th: "โรงแรม",
  say: "…",                      // ข้อความให้ระบบอ่านออกเสียงแทน vi (เช่น ST vùng → "sát thương vùng")
  src: "ROV (Liên Quân Mobile)", // ที่มา (ถ้ามี)
  parts: [ { vi: "Khách", han: "客", py: "kè", th: "แขก" }, … ], // ไม่มี han = คำเวียดแท้
  note: "… <b>漢字</b> …"        // HTML ได้, ใช้ <b> ครอบอักษรจีน
}
```

ใช้อักษรจีน **ตัวเต็ม** เสมอ (ผู้ใช้ไม่ต้องการตัวย่อบนบัตร)

## ฟีเจอร์ที่มีแล้ว

- สองชุด (แท็บ ฮั่นเวียด / คำอื่น ๆ), โหมดหน้าบัตร: เวียดนาม / อักษรจีน / ไทย
- พลิกบัตร, ก่อนหน้า/ถัดไป, สุ่ม, "จำได้แล้ว" (localStorage เฉพาะเครื่อง), รายการคำทั้งหมด
- ที่มา (`src`) แสดงท้ายหลังบัตร
- **ออกเสียง** ด้วย Web Speech API (vi-VN) ปุ่มลำโพงที่หน้าบัตร/หลังบัตร/แต่ละพยางค์ + ช่องเลือกเสียง
  - เลือกเสียงใต้อัตโนมัติถ้าชื่อเสียงมี Cần Thơ/Sài Gòn ฯลฯ
  - ผู้ใช้ใช้ iPhone/iPad และติดตั้งเสียง Siri "Vietnamese (Can Tho)" แล้ว แต่ Safari อาจไม่ส่งเสียง Siri ให้หน้าเว็บ (ยังไม่ได้รับคำยืนยันจากผู้ใช้ว่าใช้ได้หรือไม่)
- **ค้นหา** ทุกชุดพร้อมกัน: เวียดนาม (มี/ไม่มีวรรณยุกต์), อักษรจีน, พินอิน, ไทย; ผลที่เจอแค่ในหมายเหตุแสดงต่อท้ายพร้อมป้าย
- รองรับ dark mode, จอมือถือ

## ข้อเสนอที่ผู้ใช้ยังไม่ได้ตอบ/ปฏิเสธ

- ปฏิเสธ: แสดงจีนตัวย่อบนบัตร
- ยังไม่ตอบ: ปุ่ม "ทวนเฉพาะคำที่ยังจำไม่ได้", โยงตัวอักษรที่ใช้ซ้ำอัตโนมัติ, ซิงก์ความคืบหน้าข้ามเครื่อง, โน้ตสำเนียงใต้บนบัตร, บัตรสรรพนามบุรุษที่ 3 (anh ấy / cô ấy / nó / hắn …)
