## วิธีทำงานที่ตกลงกับผู้ใช้

1. ผู้ใช้ส่งคำ / วลี / ประโยค / ชื่อสกิล+คำอธิบาย มาทีละข้อความ → Claude ตัดสินเองว่าเป็นฮั่นเวียดไหม
   - มีพยางค์ฮั่นเวียดอย่างน้อยหนึ่งพยางค์ (รวมคำลูกผสม และฮั่นเวียดยุคเก่า เช่น việc 役, phép 法, bạc 白, bùa 符, câu 句, rồng 龍, xe 車) → ชุด **ฮั่นเวียด** (ไม่ใส่ `deck`)
   - ไม่มีเลย → ชุด **คำอื่น ๆ** (`deck: "other"`, ใส่ `origin`)
   - ที่มาไม่แน่ชัด → ไม่ใส่ `han` ในพยางค์นั้น และเขียนในหมายเหตุ
   - การคาดเดาที่ไม่มีแหล่งยืนยัน → เขียนในหมายเหตุขึ้นต้นด้วย **[คาดคะเน]** (ผู้ใช้ขอแบบนี้)
2. **พิมพ์ผิดบ่อย** (วรรณยุกต์ผิด / พิมพ์ Telex ค้าง เช่น ngooi=ngôi) → เดาคำที่ใช่ ใส่บัตร แล้วบอกว่าตีความเป็นคำไหน ถ้ากำกวมจริง (ความหมายเปลี่ยนมาก) ให้ถามก่อน
3. **คำซ้ำ** → ไม่เพิ่มซ้ำ บอกว่ามีแล้ว แนะนำช่องค้นหา
4. **ลำดับ:** บัตรใหม่ต่อท้ายอาร์เรย์ `WORDS` เสมอ (หน้าเว็บเรียงตามลำดับที่เพิ่ม)
   - **ยกเว้น:** คำอธิบายสกิล → แทรกต่อจากบัตรชื่อสกิลทันที แล้วตามด้วยบัตรแยกคำ (ผู้ใช้ขอ)
5. **บัตรประโยค:** ผู้ใช้ต้องการให้ **ทุกคำในประโยคมีบัตรของตัวเอง** → ทำบัตรประโยค + บัตรเดี่ยวของคำที่ยังไม่มีบัตร (ใส่บรรทัดอ้างอิงในหมายเหตุของบัตรประโยค)
6. **ที่มา (`src`)** — ใส่เฉพาะเมื่อผู้ใช้บอก:
   - ROV (Liên Quân Mobile), "แชทในเกม", "คำอธิบายสกิลในเกม (ชื่อสกิล)", "คำอธิบายความสามารถในเกม"
   - คำทั่วไปช่วงหลัง (เดินทาง ฯลฯ) ไม่มีที่มา
7. ใช้อักษรจีน **ตัวเต็ม** เสมอ (ผู้ใช้ไม่เอาตัวย่อบนบัตร)
8. ทุกครั้งที่แก้: `node --check` สคริปต์ → publish URL เดิม → ตอบเป็นภาษาไทยสั้น ๆ: ความหมาย, แยกพยางค์ (อักษรจีน+พินอิน), คำที่ใช้ตัวอักษรเดียวกัน, ข้อควรระวัง (คำพ้องเสียง), เหนือ/ใต้ถ้ามี, จำนวนบัตรสองชุด
9. ผู้ใช้สนใจ **สำเนียงใต้** → ถ้ามีคำภาคใต้/ภาคเหนือต่างกัน ให้บอก (เช่น xe lửa ↔ tàu hoả, hẻm ↔ ngõ)

## โครงสร้างข้อมูลบัตร (`const WORDS = [...]`)

```js
{
  deck: "other", origin: "คำเวียดแท้ (thuần Việt)",   // ไม่ใส่ deck = ชุดฮั่นเวียด
  src: "ROV (Liên Quân Mobile)",                       // ถ้ามี
  vi: "Khách sạn", say: "…", th: "โรงแรม",             // say = ข้อความให้ TTS อ่านแทน vi
  parts: [ { vi: "Khách", han: "客", py: "kè", th: "แขก" }, … ],
  note: "… <b>漢字</b> …"
}
```
วิธีเพิ่มท้าย: หา `s.index('\n];', s.index('const WORDS = ['))` แล้วแทรก `",\n" + card` ก่อนตำแหน่งนั้น
วิธีแทรกกลาง/ย้าย: parse วงเล็บปีกกาชั้นนอกของ WORDS เป็นบล็อก (ระวัง string) แล้วประกอบใหม่

## ฟีเจอร์ที่มีแล้ว

- สองชุด (ฮั่นเวียด / คำอื่น ๆ), โหมดหน้าบัตร เวียดนาม/อักษรจีน/ไทย, พลิก, ก่อนหน้า/ถัดไป
- ปุ่มสุ่มแบบสลับ (สุ่ม ↔ เรียงตามลำดับที่เพิ่ม), "จำได้แล้ว" (localStorage)
- ที่มา (`src`) แสดงท้ายหลังบัตร
- ออกเสียง Web Speech (vi-VN) ทั้งคำ/ทีละพยางค์ + แถวเลือกเสียง (เลือกเสียงใต้อัตโนมัติถ้าชื่อมี Cần Thơ ฯลฯ, ไม่เตือนผิดถ้าแอปไม่บอกรายชื่อเสียง)
  - ผู้ใช้ใช้ iPhone/iPad มีเสียง Siri "Vietnamese (Can Tho)" — Safari อาจไม่ส่งเสียง Siri ให้หน้าเว็บ (ยังไม่ยืนยัน)
- ค้นหาทุกชุด (เวียดนาม มี/ไม่มีวรรณยุกต์, อักษรจีน, พินอิน, ไทย; ผลในหมายเหตุแสดงต่อท้าย)

## เรื่องค้าง

- ผู้ใช้ยังไม่ตอบ: ป้ายหมวด "เดินทาง", ปุ่มทวนเฉพาะคำที่ยังจำไม่ได้, บัตรสรรพนามบุรุษที่ 3, บัตรแยกคำของ Không sao cả… / Hãy là chính bạn / Tung chiêu trúng đích, เพิ่มเรื่อง 分 ในหมายเหตุ Bên kia đường
- ข้อความตัดไม่ครบ: "Giới hạn tốc đánh tối đa t…", "Giới hạn tốc chạy + …" (รอข้อความเต็ม)
- "nhường e 5 mạnh ik" (แชท) ยังไม่ทำบัตร — ไม่แน่ใจ mạnh
